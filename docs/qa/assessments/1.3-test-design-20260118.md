## Risk Coverage

| Risk                        | Probability | Impact | Tests Mitigating                  |
| --------------------------- | ----------- | ------ | --------------------------------- |
| App fails to start          | Low         | High   | Manual verification               |
| Health check false positive | Low         | Medium | 1.3-UNIT-004, 1.3-UNIT-006        |
| CORS blocks valid requests  | Medium      | High   | Code review, manual test          |
| Sensitive data in logs      | Low         | High   | 1.3-UNIT-008 (recommended)        |
| Inconsistent error format   | Medium      | Medium | 1.3-UNIT-009 through 1.3-UNIT-015 |
| Missing env crashes app     | High        | High   | 1.3-UNIT-016 through 1.3-UNIT-022 |
