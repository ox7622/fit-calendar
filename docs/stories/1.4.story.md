## Dev Notes

### BotFather Setup Instructions

To configure the bot in BotFather:

1. **Create Bot** (if not already done):

    - Open Telegram and search for `@BotFather`
    - Send `/newbot` command
    - Follow prompts to name your bot (e.g., "FitCalendar Bot")
    - Choose a username ending in `bot` (e.g., `fitcalendar_bot`)
    - Save the token to `TELEGRAM_BOT_TOKEN` in `.env`

2. **Set Commands List**:

    - Send `/setcommands` to BotFather
    - Select your bot
    - Send the command list:
        ```
        start - Start the bot and open Mini App
        ```

3. **Configure Menu Button** (Mini App launch):

    - Send `/setmenubutton` to BotFather
    - Select your bot
    - Choose "Web App"
    - Enter button text: "Open Schedule"
    - Enter Mini App URL: Your deployed Mini App URL

4. **Set Bot Description** (optional):

    - Send `/setdescription` to BotFather
    - Select your bot
    - Enter description in Russian:
        ```
        FitCalendar - ваш помощник для записи на фитнес-занятия
        ```

5. **Generate Webhook Secret**:
    - Generate a secure random string (32+ characters)
    - Save to `TELEGRAM_WEBHOOK_SECRET` in `.env`
    - This secret is validated in webhook requests

### Webhook Signature Validation

Telegram sends a secret token in the `X-Telegram-Bot-Api-Secret-Token` header. Validate it matches `TELEGRAM_WEBHOOK_SECRET`.

```typescript
// Webhook validation
const secretHeader = request.headers['x-telegram-bot-api-secret-token'];
if (secretHeader !== process.env.TELEGRAM_WEBHOOK_SECRET) {
    throw new UnauthorizedException('Invalid webhook secret');
}
```

```typescript
describe('BotController', () => {
    let controller: BotController;
    let botService: BotService;

    beforeEach(async () => {
        const module = await Test.createTestingModule({
            controllers: [BotController],
            providers: [
                {
                    provide: BotService,
                    useValue: { handleUpdate: jest.fn() },
                },
            ],
        }).compile();

        controller = module.get(BotController);
        botService = module.get(BotService);
    });

    describe('webhook', () => {
        it('should process valid update', async () => {
            const update = { update_id: 123, message: {} };
            await controller.webhook(update, 'valid-secret');
            expect(botService.handleUpdate).toHaveBeenCalledWith(update);
        });

        it('should reject invalid secret', async () => {
            await expect(controller.webhook({}, 'invalid-secret')).rejects.toThrow(UnauthorizedException);
        });
    });
});
```
