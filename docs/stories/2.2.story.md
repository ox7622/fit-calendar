# Story 2.2: Today's Schedule View (Mini App)

## Status

Complete

## Story

**As a** mini-app user,
**I want** to see today's schedule in the Mini App,
**so that** I can quickly check what fitness classes are available.

## Acceptance Criteria

1. `ScheduleClass` and `DaySchedule` types defined in `shared/types/schedule.types.ts`
2. `scheduleApi` client wraps the schedule endpoints with proper typing
3. `scheduleApi` is exported from `shared/api/index.ts`

## Tasks / Subtasks

-   [x] **Task 1: Create Schedule Types** (AC: 1)

    -   [x] Create `apps/mini-app/src/shared/types/schedule.types.ts`
    -   [x] Define `ScheduleClass` interface with all required fields
    -   [x] Define `DaySchedule` interface

-   [x] **Task 2: Create scheduleApi Client** (AC: 2)

    -   [x] Create `apps/mini-app/src/shared/api/schedule.api.ts`
    -   [x] `getToday()` — wraps `GET /schedule/today`
    -   [x] `getWeek()` — wraps `GET /schedule/week` and returns `DaySchedule[]`
    -   [x] `getByDate(date)` — wraps `GET /schedule/:date`

-   [x] **Task 3: Export from index** (AC: 3)

    -   [x] Update `apps/mini-app/src/shared/api/index.ts` to export `scheduleApi`

## Dev Notes

-   `getWeek()` API returns `WeekScheduleDto { days: DaySchedule[] }`, so the client unwraps it to `DaySchedule[]`
-   TypeScript strict mode enabled — all fields are typed
