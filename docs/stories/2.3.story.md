# Story 2.3: Weekly Calendar View + Updated SchedulePage

## Status

Complete

## Story

**As a** mini-app user,
**I want** to view both today's and the week's schedule in the Mini App,
**so that** I can plan my fitness activities.

## Acceptance Criteria

1. SchedulePage has tab toggle: "Сегодня" / "Неделя"
2. Today tab fetches `scheduleApi.getToday()` with loading skeletons and empty state
3. Week tab shows horizontal scrollable day selector with date numbers and day abbreviations
4. Selected day in week tab shows a list of classes (or "Занятий нет" if empty)
5. Navigation ← → buttons to go to previous/previous week
6. Pull-to-refresh via "Обновить" button
7. Today is highlighted in the day selector
8. Clicking a class navigates to `/schedule/:id`
9. Route `/schedule/:id` exists with a `ClassDetailPage` placeholder

## Dev Notes

-   Uses `date-fns` for date formatting: `format`, `addDays`, `startOfDay`, `isToday`
-   Uses `ru` locale from `date-fns/locale` for Russian date formatting
-   Week offset enables navigating to past/future weeks
-   `weekOffset=0` uses efficient `getWeek()` API; other offsets use per-day `getByDate()` calls
-   Day selector dots indicate days with classes
