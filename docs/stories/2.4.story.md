# Story 2.4: Bot /today Command

## Status

Complete

## Story

**As a** Telegram bot user,
**I want** to type `/today` and see today's fitness schedule,
**so that** I can quickly check classes without opening the Mini App.

## Acceptance Criteria

1. `/today` command sends today's schedule with date header in Russian
2. Each class shown as `⏰ HH:mm — ClassName (CoachName, Xмин)`
3. Footer with Mini App inline button if `MINI_APP_URL` is configured
4. If no classes today: "Сегодня занятий нет 😴"
5. Works in both the API bot module and the standalone `apps/bot`
