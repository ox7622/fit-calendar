# Story 2.5: Class Card Component

## Status

Complete

## Story

**As a** mini-app user,
**I want** each fitness class shown as a visually clear card,
**so that** I can quickly scan the schedule.

## Acceptance Criteria

1. `ClassCard` component renders coach photo (or initials fallback), class name, time range, duration badge, difficulty badge
2. Difficulty badge uses green/yellow/red color coding
3. Tappable with `active:scale-[0.98] transition` micro-interaction
4. In-progress indicator: pulsing green dot if `now >= startTime && now < endTime`
5. Clicking card calls `onClick` prop (for navigation to detail page)
6. `SkeletonCard` shows animated shimmer placeholder with same layout
7. Both components exported from `components/index.ts`

## Dev Notes

-   `getInitials(name)` takes first character of each space-split word, uppercased, max 2 chars
-   `isInProgress(startTime, endTime)` compares `Date.now()` with parsed ISO timestamps
-   Uses `@/` path alias (configured in `tsconfig.json` and `vite.config.ts`)
-   Difficulty label map: `beginner` → "Начальный", `intermediate` → "Средний", `advanced` → "Продвинутый"
-   The `@/` path alias was added to `apps/mini-app/tsconfig.json` as part of this story
