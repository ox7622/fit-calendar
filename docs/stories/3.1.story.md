# Story 3.1: Training Detail View (Mini App)

## Status

Complete

## Story

**As a** Mini App user,
**I want** to tap on a class card and see full details about the class,
**so that** I can learn about the training before attending.

## Acceptance Criteria

1. Tapping a class card navigates to `/schedule/:id`
2. Fetch class details from `GET /schedule/:id` via `scheduleApi.getById(id)`
3. Show: class name (large heading), coach avatar + name, date + time in Russian locale, duration badge, difficulty badge, impact type tags, equipment list (if non-empty), description (if present)
4. Back button using `useNavigate(-1)`
5. Full-page shimmer skeleton while loading
6. Error state if fetch fails
7. Page has no bottom nav (handled by Router)
