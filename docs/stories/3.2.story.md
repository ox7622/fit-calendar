# Story 3.2: Training Metadata API

## Status

Complete

## Story

**As a** Mini App frontend,
**I want** metadata endpoints for training types, difficulty levels, and impact types,
**so that** filter options can be populated without hardcoding them in the client.

## Acceptance Criteria

1. `GET /schedule/metadata/training-types` returns active `TrainingType[]` (id, name, description, difficulty, impactTypes, equipment)
2. `GET /schedule/metadata/difficulty-levels` returns `[{value, label}]` with Russian labels
3. `GET /schedule/metadata/impact-types` returns `[{value, label}]` with Russian labels
4. No authentication required on metadata endpoints
5. DTOs defined with Swagger decorators
