# Story 3.3: Schedule Filtering API

## Status

Complete

## Story

**As a** Mini App user,
**I want** to filter the schedule by difficulty, impact type, training type, or coach,
**so that** I see only the classes that match my preferences.

## Acceptance Criteria

1. `GET /schedule/today`, `GET /schedule/week`, `GET /schedule/:date` accept optional filter query params
2. Filter params: `difficultyLevel`, `coachId`, `trainingTypeId`, `impactType` (comma-separated), `includeCancelled`
3. `ScheduleFilterDto` uses `class-validator` and `class-transformer`
4. `impactType` comma-separated string is transformed to `string[]`
5. `includeCancelled` string `"true"/"false"` is transformed to `boolean`
6. Filters applied via TypeORM `where` conditions with relations
