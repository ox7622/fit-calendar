# Story 3.4: Filter UI Component (Mini App)

## Status

Complete

## Story

**As a** Mini App user,
**I want** a slide-up filter sheet to narrow down the schedule,
**so that** I can quickly find classes that match my preferences.

## Acceptance Criteria

1. `FilterSheet` slide-up sheet with backdrop, animations
2. Sections: Difficulty (3 toggle buttons), Impact Type (4 toggle buttons multi-select), Training Type (list), Coach (list)
3. Active filter count badge on filter button in header
4. "Clear All" and "Apply" buttons
5. `SchedulePage` has filter state and passes active filters to API calls
6. `scheduleApi.getMetadata()` loads training types on mount
7. `coachesApi.getList()` loads coaches on mount
