# Story 3.5: Impact Type Indicators Component

## Status

Complete

## Story

**As a** Mini App user,
**I want** visual impact type indicators on class cards and detail views,
**so that** I can quickly identify what type of workout a class offers.

## Acceptance Criteria

1. `ImpactTypeBadge` pill badge with icon and Russian label
2. Colors: cardio=orange, strength=red, flexibility=green, balance=blue
3. Icons: Flame (cardio), Dumbbell (strength), Activity (flexibility), Scale (balance)
4. Props: `type`, optional `size` (`'sm' | 'md'`)
5. `ClassCard` uses `ImpactTypeBadge` for impact types
6. Exported from `components/index.ts`
