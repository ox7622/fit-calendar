# Story 4.1: Coach List API & View

## Status

Complete

## Story

**As a** Mini App user,
**I want** to see a list of coaches with their photo and specialization,
**so that** I can find and learn about the fitness coaches at the club.

## Acceptance Criteria

1. `GET /coaches` returns `{ id, name, photoUrl, specializations }` sorted by name ASC
2. `GET /coaches/:id` returns full coach detail `{ id, name, bio, photoUrl, specializations, certifications }`
3. `GET /coaches/:id/schedule` returns upcoming classes for coach (next 7 days)
4. `CoachesPage` fetches and displays coaches as a list with 48px circle avatar or initials, name (font-semibold), primary specialization
5. Loading skeletons (3 rows) while fetching
6. Tapping a coach navigates to `/coaches/:id`
7. Empty state: "Тренеры не найдены"
8. Error state with retry button
