# Story 4.2: Coach Profile Detail View

## Status

Complete

## Story

**As a** Mini App user,
**I want** to see a full profile page for each coach,
**so that** I can learn about their background, specializations, and certifications.

## Acceptance Criteria

1. `CoachDetailPage` reads `:id` from `useParams`, fetches `coachesApi.getById(id)`
2. Large coach photo (120px circle) at top, or initials fallback
3. Full name displayed as heading
4. Bio section shown if present
5. Specializations displayed as tags/badges
6. Certifications shown as bulleted list (if non-empty)
7. "Расписание тренера" button navigates to `/coaches/:id/schedule`
8. Back button calls `useNavigate(-1)`
9. Loading skeleton (full page shimmer)
10. Error state with back button
