# Story 4.3: Coach Schedule View

## Status

Complete

## Story

**As a** Mini App user,
**I want** to see the upcoming schedule for a specific coach,
**so that** I can plan to attend their classes.

## Acceptance Criteria

1. `CoachSchedulePage` reads `:id` from `useParams`, fetches `coachesApi.getSchedule(id)`
2. Classes displayed with `ClassCard` components sorted by startTime
3. Classes grouped by date with a date header (e.g. "23 февраля, понедельник")
4. Loading skeleton (3 SkeletonCard)
5. Empty state: "Нет предстоящих занятий"
6. Error state with back button
7. Back button calls `useNavigate(-1)`
8. No AppShell (no bottom nav)
