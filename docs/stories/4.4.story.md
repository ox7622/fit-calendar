# Story 4.4: Club Information Page

## Status

Complete

## Story

**As a** Mini App user,
**I want** to see contact and operational information about the fitness club,
**so that** I can find the club and know when it is open.

## Acceptance Criteria

1. `ClubModule` created in `apps/api/src/modules/club/`
2. `GET /club-info` (no auth) returns `ClubInfoDto { id, name, address, phone, workingHours, latitude, longitude, logoUrl }`
3. If no DB record exists, return a default stub (not 404)
4. `ClubModule` registered in `ApiModule`
5. `ClubPage` fetches `clubApi.getInfo()` on mount
6. Displays: club name (heading), address with MapPin icon, phone with Phone icon (clickable tel: link)
7. Working hours table: Mon–Sun in Russian (Пн–Вс), "Выходной" for null days
8. Loading skeleton, error state with retry button
9. `club.api.ts` created at `apps/mini-app/src/shared/api/club.api.ts`
