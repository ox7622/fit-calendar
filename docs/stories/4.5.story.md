# Story 4.5: Map Location Link

## Status

Complete

## Story

**As a** Mini App user,
**I want** to open the club location in Google Maps,
**so that** I can easily navigate to the fitness club.

## Acceptance Criteria

1. "Показать на карте" button in `ClubPage`
2. If `latitude` and `longitude` present: opens `https://maps.google.com/?q={lat},{lon}` in new tab
3. Else: opens `https://maps.google.com/?q={encodeURIComponent(address)}`
4. Uses `MapPin` icon from lucide-react on the button
5. On Telegram Mini App: uses `window.open(url)` (works on iOS/Android)
